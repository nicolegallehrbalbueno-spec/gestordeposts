# Gestor de Posts

Painel para organizar, preparar e acompanhar conteúdos para divulgação em grupos.

## Primeira etapa

Esta versão é uma interface estática. Primeiro validamos que o site funciona no GitHub Pages; depois adicionaremos as funcionalidades e a integração com Supabase.

## Arquitetura planejada

- GitHub: código e versionamento
- Supabase: autenticação, banco e armazenamento
- Facebook: publicação manual pelo usuário

Não armazenaremos senha do Facebook nem faremos publicação automática em grupos.
